# RepLog

A native iOS workout tracker for lifting. Everything stays on the phone — no
account, no sync, no server.

## Features

- **Log** — workout history grouped by month; tap a session to open it.
- **Active workout** — weight, reps, RPE and notes per set, with your last
  performance pre-filled as placeholders.
- **Routines** — build, edit, duplicate and reorder them, then start a workout
  from one.
- **Exercise library** — 12 categories, 150+ exercises, add your own.
- **Statistics** — volume, estimated 1RM, personal records and charts.
- **Rest timer** — a bar inside the session, with a notification when it's up.
- **kg or lb**, globally or per exercise.
- **CSV in and out** — export your history, or import a file to rebuild the app.
- **Apple Health** — optional: reads bodyweight, writes finished workouts.

No accounts, no paywall, nothing sent anywhere.
